## Task 1

### 1. JDK,JRE,JVM的定义和关系：

JDK包含JRE,JRE包含JVM

-**JDK** 是java开发的工具包，包含了JRE和java的开发工具，开发和编译java源代码必须安装JDK

-**JRE **是java运行环境，仅仅用于运行编译好的程序

-**JVM **是java的运行载体，用以执行class字节码文件

### 2.为什么装好这些工具后，JAVA程序可以被编译和运行：

JDK内部自带编译器和运行工具，同时还内置了JRE和JVM
